# Archived Documents

This directory contains historical project records from Phase 1 and Phase 2
infrastructure work, as well as staging-era operational guides.

These documents remain available for **historical reference only**. They no
longer represent active operational guidance:

- The staging environment (`staging.higaet.com`) has been retired.
- The only active deployment target is production: `https://higaet.com`.
- The active MilesWeb deployment path lives in
  `docs/infrastructure/milesweb-deployment-guide.md`.

For current runbooks, health checks, deployment procedures, and rollback
guidance, see `docs/runbooks/` and `docs/infrastructure/` (root, not this
archive).
